# AGENTS.md stays small

## Goal

`ki-repo`'s review checks that a repository's `AGENTS.md` holds only what is specific to that repository, so guidance a skill or the user's own instructions already carry does not creep back after the fold.

## Context

AGENTS-FOLD a, taken in the Cairn summit's change Where guidance lives (15), folded the core repositories' `AGENTS.md` down to what is their own, and set that audit checks it stays so, once the tools are back on, with audit and conform on the core repositories. `ki-repo`'s rubric has no item for it, and nothing else carried it. The placement ladder in `ki-authoring`'s [knowledge-promotion standard](../../skills/keystone/ki-authoring/references/standard-knowledge-promotion.md#41-placement-ladder) says what belongs at each layer.

The change closed on 19 November 2026 with this carried here; its text at its last revision is [Where guidance lives (15), gap 2](https://github.com/krisb/ki-cairn-store/blob/3fd8cee865304baf91d30708ac8c58df5b18270b/work/cairn/cairn.summit/15-where-guidance-lives.change.md#72-gaps).

## Boundary

One `ki-repo` rubric item, judged or partly mechanical, and the review checklist line that names it. It does not rewrite any repository's `AGENTS.md`, nor change the placement ladder.

## Discussion

### Options

- a) A judged item in `ki-repo`'s review: each section of `AGENTS.md` is either specific to the repository or a pointer to the skill or file that holds it; a mechanical warning may follow later for a file over a set length. Recommended, medium confidence: specific-to-the-repository is a judgement, and a length limit alone would flag the wrong files.
- b) A mechanical warning only, on length, leaving content to review.
