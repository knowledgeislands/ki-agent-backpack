# Agentic system

An agentic system lets work get done by models that decide some of their own steps, rather than by code that fixes every step in advance.

An agentic system is any system in which [models][industry.model] direct some of their own steps and tool use. It is built in two ways, often together: **workflows**, where code sets the path and orchestrates models and tools along it, and [agents][industry.agent], where the model directs its own process. It is the umbrella over every term in this graph: one agent with its subagents, an agent team, or agents in several systems reaching each other as remote agents.

## Our conventions

Knowledge Islands' own agents, with the skills and tools they work through, make up one agentic system in this sense.
