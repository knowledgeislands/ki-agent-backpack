## 1. Introduction

The sources behind [the enforcement standard](standard-authoring.md), [the Markdown standard](standard-markdown.md), [the TOML standard](standard-toml.md), [the white-paper standard](standard-whitepapers.md), [knowledge promotion](standard-knowledge-promotion.md), [the review standard](standard-review.md), and the seven format standards: [format](standard-formats-format.md), [standard](standard-formats-standard.md), [change](standard-formats-change.md), [sources](standard-formats-sources.md), [record](standard-formats-record.md), [design](standard-formats-design.md) and [presentation](standard-formats-presentation.md). Mode REFRESH reads this file, re-fetches each outside source, diffs it against the conventions, then **bumps the `last reviewed` dates** and refreshes [Last review](#4-last-review) (what changed is recorded in the commit, not a changelog). The house style is mostly internally owned, but it sits on top of these external tools and specs, which move — so this is the skill's memory of what it rests on.

[Industry white-paper authoring](standard-whitepapers.md) is an owner-directed synthesis of editorial practice: reader-led argument, calibrated claims, practical implications and substantive review. It is an internal authoring convention, not an external specification or a prescribed chapter model. Private production evidence and the promotion receipt remain with the originating repository; this public standard carries only the generalised rules.
